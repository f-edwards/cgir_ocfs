# The effect of a recurring, unconditional, cash transfer on child welfare system contact and foster care: a randomized controlled trial

This repository contains all software needed to replicate Edwards et al. "The effect of a recurring, unconditional, cash transfer on child welfare system contact and foster care: a randomized controlled trial". 

Users can simulate study results based on aggregated event counts using the contained scripts. 

`make_all.R` will proceed through all needed steps of the analysis. Users can configure this file to either simulate results from aggregated data (provided) or run on observed data (not provided).

Note that individual-level data on child welfare events are confidential by New York law, and are not shared here or elsewhere.
